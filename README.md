# STEM Racing - Simulador de Reação

Um simulador de tempo de reação profissional desenvolvido para a equipe Stem Racing.

## 🚀 Tecnologias
- **React 19 + Vite**
- **TypeScript**
- **Framer Motion** (Animações Premium)
- **Web Audio API** (Sintetizadores para feedback sonoro)
- **Canvas Confetti**

## 🏁 Funcionalidades
- Sequência de luzes estilo F1.
- Detecção precisa de queima de largada.
- Histórico de melhores tempos e última tentativa (persistido localmente).
- Toggle de áudio.
- Suporte total a toque e teclado (Espaço).

## 🛠️ Como rodar
1. `npm install`
2. `npm run dev`

## 📦 Deploy
O projeto está configurado para deploy automático na Vercel via GitHub.
